# Voice Journal

A cozy vintage-style voice journaling app built with React Native and Expo.

## Features

- Voice recording
- Speech-to-text transcription
- Emotion tags
- Timeline view

## Tech Stack

- React Native
- Expo Router
- TypeScript
- pnpm Workspace
- Node.js
